# 计费说明

## 单价

- 模型：`qwen-audio-3.0-asr-flash-filetrans`
- 华北2（北京）：**0.00022 元/秒**（按识别出的语音内容时长计费，输出不计费）
- 国际地域（新加坡等）：**0.00026 元/秒**
- 免费额度：仅华北2（北京）有免费额度，**36,000 秒（10 小时）**；有效期自开通百炼/模型发布/申请通过之日起 90 天内（以较晚者为准）。

## 预估公式

```
预估费用(元) = 语音内容时长(秒) × 0.00022
```

示例（按 0.00022 元/秒）：

| 语音内容时长 | 预估费用 |
|----------|----------|
| 1 分钟 | ¥0.0132 |
| 10 分钟 | ¥0.1320 |
| 1 小时 | ¥0.7920 |

## 时长来源

- prepare 阶段：本地文件优先用 `ffprobe`/`wave` 探测**原始音频时长**，仅作粗略参考；公网 URL 无法本地探测。
- generate 成功后：优先取结果 JSON 中 `transcripts[].content_duration_in_milliseconds` 之和（语音内容时长），缺失时回退 `original_duration_in_milliseconds`。
- 服务端只对判定为语音内容的时长计量计费，非语音内容不计量、不计费。

## 说明

- 预估值仅供确认方案时参考，**最终以百炼账单为准**。
- `prepare` 阶段不调 API、不产生费用；费用发生在转写任务成功之后。
- 本地文件上传到百炼临时 OSS 不产生 ASR 费用，但临时 URL/上传凭证接口仅适合测试，生产环境请使用阿里云 OSS 稳定存储。
- 同一次音频重复 generate 会重复计费；令牌一次性机制用于避免重复提交。
